1. Загрузите ВСЁ содержимое папки в репозиторий GitHub (включая скрытую папку .github).
2. Actions -> Build APK -> дождитесь зелёной галочки -> скачайте артефакт MinimalLauncher-apk.
3. APK на флешку -> установка через "Управление файлами" на магнитоле.

Своя машина: положите PNG с прозрачным фоном в app/src/main/res/drawable-nodpi/
  car.png - одна картинка;  car_0.png ... car_35.png - кадры вращения (крутится пальцем).
